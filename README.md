🔐 PassMan – Your Personal Password Manager
PassMan is a secure, modern, and user-friendly password manager built with Next.js and powered by MongoDB for scalable data storage. Designed with a sleek UI and animated icons to enhance user experience, PassMan helps you store and manage your passwords with ease and confidence.

✨ Features
🔒 Secure Storage using MongoDB with encryption

🚀 Built with Next.js for fast and scalable performance

🎨 Animated Icons for a modern and intuitive user interface

📱 Responsive Design for desktop and mobile access

🧠 User-Friendly account management and vault organization

📥 Easily add, update, and delete password entries

🛠 Tech Stack
Frontend & Backend: Next.js

Database: MongoDB

Styling: Tailwind CSS 

Icons: Animated SVG based icons for enhanced UI using Lordicons.com
